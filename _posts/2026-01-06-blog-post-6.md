# Could\_We\_Handle\_An\_ABI\_Break\_Today

C++编译产物的ABI兼容问题（如：C++26编译产物想link到另一个C++23编译二进制文件）。
参考abseil，用**cpp版本宏（\_\_cplusplus）**、**预定义特性宏**、**\_\_has\_include** 来在选择不同版本API，这样可以保证不同编译环境 共用一套头文件 是安全的。
其他方法：三方包管理器如vcpkg connan, 或者直接build from source

# Cache\_Friendly\_Cpp

遍历查找速度benchmark时，sorted std::vector为何总是比 unordered\_set  set unsorted std::vector 快？原因：Cache友好。
CPU L1 L2 L3 Cache、CPU预取 Prefetch，设计数据应考虑：**可预测的内存访问模式+高度的locality。**
多线程的false sharing规避：1）单个线程访问的（共享的、涉及数据竞争的）数据对齐到cacheline；2）单个线程访问（不共享的、不涉及数据竞争的）局部变量
总结：**线性顺序访问数据，减少数据大小（尤其优化Padding bits）。避免长分支，避免间接跳转，减少热点代码（频繁执行的代码）size。**
